Privacidade

Resumo: o jogo não coleta, não envia e não vende nenhum dado seu. Não tem cadastro, anúncios nem rastreamento. Tudo o que ele guarda fica no seu aparelho.

O que fica no seu aparelho

  • Recorde, estatísticas das corridas, conquistas, progresso do tutorial e as suas opções.
  • Ficam no armazenamento do navegador (ou do app instalado) neste aparelho, e só o próprio jogo os lê. Nada disso é enviado para lugar nenhum.
  • Para apagar: menu → Estatísticas → Apagar estatísticas apaga as estatísticas; para apagar tudo (recorde, conquistas e opções também), limpe os dados do site nas configurações do navegador.

Feedback (opcional)

  • O botão "Enviar feedback" abre um formulário do Google já preenchido com a versão do jogo e as suas estatísticas (distâncias, o que encerrou as corridas, quantas ações). Esses dados não incluem nome, e-mail nem outro dado pessoal; o formulário só pede um apelido se você quiser se identificar.
  • Nada é enviado se você não tocar em "Enviar" no formulário. As respostas vão para uma planilha do desenvolvedor e servem só para melhorar o jogo.
  • O envio passa pelo Google Formulários, que segue a política de privacidade do Google.

Hospedagem

O jogo é publicado pelo GitHub Pages. Como qualquer site, o GitHub pode registrar dados técnicos de acesso, como o endereço IP, conforme a declaração de privacidade do GitHub. Fora isso, o jogo não se comunica com nenhum outro serviço: até as fontes vêm do próprio site.

Permissões

O jogo não usa câmera, microfone, localização nem contatos. A vibração só funciona se você ligá-la em Opções.
